# U Link 产品模块说明

更新时间：2026-08-22

## 记录目的

本文用于沉淀 U Link 的产品模块口径。后续制作首页、内容入口、客户演示原型或后台内容分类时，优先参考本文，不再临时凭空生成栏目。

本文只描述产品方向和模块关系，不代表所有模块都已经上线，也不代表第一版 MVP 必须全部实现。

学生端文案应避免出现“第三方协作”“后台配置”“合作方资源待接入”等运营视角表达。可以表达为“咨询”“预约”“了解”“活动”“服务入口”等学生可理解的动作。

## 核心定位

U Link 是面向 16-26 岁青年的成长生态平台。

核心表达：

- 以咖啡空间为入口。
- 以金融为底色。
- 以规划为牵引。
- 以实践为内核。
- 连接校园与职场、本土与世界。

平台不是单一内容工具，也不是只服务某一所学校的小程序。第一阶段可以从学生认证、职业规划、金融职业内容和服务入口切入，后续逐步扩展文化交流和国际体验。

## 核心架构

U Link 的模块主轴为：

```text
U Link 咖啡空间
  |
  |-- 职业规划
  |-- 实习实践
  |-- 自主创业
  |
  v
金融机构底色
```

第一版小程序首页可以先突出“职业规划”“实习实践”“金融底色”和“文化交流”等学生侧能理解的入口；“自主创业”更适合作为后续出口或高级模块预留，不宜在 MVP 首页过早放大。

## 三个成长断层

产品要回应青年从校园走向社会时常见的三个断层：

### 认知断层

用户问题：

- 不清楚自己适合什么。
- 不知道职业路径怎么走。

U Link 回应：

- 职业测评。
- 规划咨询。
- 生涯课程。
- 简历与求职支持。

### 实践断层

用户问题：

- 缺少真实商业场景的历练机会。
- 很多内容停留在课堂和信息层面。

U Link 回应：

- 门店运营。
- 实训营。
- 企业实习。
- 线上或线下培训。
- 真实项目参与。

### 视野断层

用户问题：

- 缺少国际化经历和跨文化视野。
- 对本土文化与世界连接缺少具体路径。

U Link 回应：

- 赴美实习。
- 新加坡访学。
- 文化交流。
- 非遗文化项目。
- 中英文内容页。

## 学生端首页模块建议

首页模块应表达“产品地图”，不要表达成“已经上线的完整栏目清单”。

建议结构：

### 顶部主卡：U Link 成长服务地图

建议文案：

> 从校园身份出发，连接职业规划、实习实践、金融资源与文化交流。第一阶段先聚焦学生认证与职业发展服务。

### 职业规划

学生端摘要：

> 测评、规划、简历与课程支持。

可承接能力：

- 职业测评。
- 生涯规划咨询。
- 简历制作或优化。
- 职业方向内容。
- 导师或课程内容。

注意：

- 如果具体测评、课程或简历服务尚未确定，不要写成“已上线课程”或“立即测评”。
- 可使用“了解方向”“预约咨询”“服务入口”等中性表达。

### 实习实践

学生端摘要：

> 实训营、岗位介绍与实践机会。

可承接能力：

- 安联实训营。
- 线上或线下培训。
- 金融机构岗位介绍。
- 企业实践机会咨询。
- 门店运营或真实项目参与。

注意：

- 未确认具体岗位和名额前，不要写“岗位申请”“立即报名”。
- 可使用“实践机会咨询”“实训信息”“岗位了解”等表达。

### 金融底色

学生端摘要：

> 金融沙龙、财商课与机构资源。

可承接能力：

- 金融沙龙。
- 行业趋势分享。
- 财富管理和职业规划内容。
- 财商课程。
- 金融机构实践网络。
- 保险或财富管理方向内容。

注意：

- 可以强调“金融机构底色”和“金融资源连接”。
- 不要在学生首页直接堆合作机构名称，除非已经获得展示授权并有明确运营目的。

### 文化交流

学生端摘要：

> 非遗文化、中外交流与研学路线。

可承接能力：

- 非遗文化项目。
- 本土文化路线。
- 中外文化交流。
- 赴美工作与旅游项目信息。
- 新加坡访学或其他国际交流信息。
- 入境寻根路线和中英文内容页。

注意：

- 该模块属于后续生态扩展方向，MVP 首页可以预留但不要喧宾夺主。
- 未上线具体路线前，不要写“立即报名”“已开放路线”。

### 咖啡空间

咖啡空间是线下入口和流量入口，适合放在首页主卡、活动入口或线下空间页中，而不是四宫格里作为普通内容栏目。

可承接能力：

- 线下空间介绍。
- 活动预告。
- Workshop Pass。
- 咨询预约。
- 非遗体验专区。
- 新生伴手礼或主题活动。

### 自主创业

自主创业是长期出口能力，适合作为后续模块预留。

可承接能力：

- 创业认知。
- 项目实践。
- 商务谈判。
- 客户对接。
- 学生参与产品研发或门店运营。

注意：

- 第一版首页不建议突出自主创业，避免 MVP 显得过大。

## 首页不建议出现的表达

学生端首页避免使用：

- 第三方协作。
- 战略合作伙伴。
- 资源待接入。
- 后台配置。
- 供应商。
- 购买会员。
- 会员套餐。
- 立即开通。

如需表达外部服务，可以改成：

- 服务入口。
- 咨询预约。
- 了解详情。
- 活动信息。
- 实践机会咨询。

## MVP 首页优先级

第一阶段首页建议优先级：

1. 学生认证状态和基础可用路径。
2. 职业规划。
3. 实习实践。
4. 金融底色。
5. 文化交流预留。
6. 咖啡空间活动或咨询入口。

会员购买暂缓时，不要在首页出现购买转化入口。
